Portafolio Personal

Descripción del Proyecto

Este proyecto consiste en un sitio web de portafolio personal creado para presentar el perfil, las habilidades, las herramientas y los proyectos de Mariana Hernández, Desarrolladora Full-Stack Junior.

El sitio incluye una presentación personal, una sección de habilidades y herramientas técnicas, una sección de proyectos destacados y la información de contacto. También ofrece enlaces al CV, al perfil de GitHub y a las demostraciones de los proyectos.

Tecnologías y Técnicas

El proyecto fue desarrollado utilizando:

- HTML5: Estructura semántica y organización del contenido del sitio web.
- CSS3: Estilos, distribución y diseño visual.
Flexbox: Distribución flexible y alineación de elementos.
- CSS Grid: Organización de las tarjetas de proyectos.
- BEM: Convención para nombrar las clases CSS y mantener un código limpio y organizado.
- Media Queries: Diseño responsivo para adaptar el sitio a diferentes tamaños de pantalla.
- CSS Gradients: Degradados radiales y lineales para efectos visuales y capas sobre imágenes.
- CSS Positioning: Posicionamiento relativo y absoluto para superponer elementos y controlar su ubicación.

Personal Portfolio Website

Project Description

This project is a personal portfolio website created to showcase the profile, skills, tools, and projects of Mariana Hernández, a Junior Full-Stack Developer.

The website includes a personal introduction, a list of technical skills and tools, a featured projects section, and contact information. It also provides links to the developer's CV, GitHub profile, and project demonstrations.

Technologies and Techniques

The project was developed using:

- HTML5: Semantic structure and organization of the website content.
- CSS3: Styling, layout, and visual design.
- Flexbox: Flexible layout and alignment of elements.
- CSS Grid: Organization of project cards.
- BEM: Naming convention for CSS classes to maintain clean and organized code.
- Media Queries: Responsive design to adapt the website to different screen sizes.
- CSS Gradients: Radial and linear gradients for visual effects and image overlays.
- CSS Positioning: Relative and absolute positioning to layer elements and control their placement.
